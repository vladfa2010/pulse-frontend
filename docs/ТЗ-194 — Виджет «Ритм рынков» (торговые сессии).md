## 1. Назначение

Интерактивная карта торговых сессий мировых бирж для публичной страницы
`/calendar` (без энтитлментов): глифовое поле ASCII с реальным днём/ночью
(солнечный терминатор по NOAA), таймлайн сессий 00–24 UTC, список бирж со
статусами и обратным отсчётом. Данные о сессиях не персональные.

### 3.3 Время

- `wallClock(date, tz)` — «стенные часы» зоны: `Intl.DateTimeFormat('en-GB',
  {timeZone: tz || 'UTC', hourCycle: 'h23', year/month/day, weekday: 'short',
  hour/minute/second: '2-digit'})`, разбор через `formatToParts` →
  `{dow(Sun=0…Sat=6), h, m, s, y, mo, d, min = h*60+m}`. Форматтеры кэшируются
  по зоне (`fmtCache`).
- `isOpen(ex, date)` — `always → true`; без tz/open/close → `false`;
  `days.includes(dow по tz биржи)`; `openMin ≤ min < closeMin`.
- `fmtCD(ms)` — `max(0, ms)` → «`H ч MM м`» / «`M м`».
- `tzOffsetMs(date, tz)` = `Date.UTC(w.y, w.mo−1, w.d, w.h, w.m, w.s) − date.getTime()`
  — полная локальная стена без модулей (иначе зоны UTC+13/+14 ломаются через
  полночь).
- `localToInstant(w, hm, tz)` — локальная стена → инстант UTC, **две итерации**
  (корректность через DST-переходы):
  `wall = Date.UTC(w.y, w.mo−1, w.d, ⌊hm/60⌋, hm%60)`;
  `inst = new Date(wall − tzOffsetMs(new Date(wall), tz))`;
  `inst = new Date(wall − tzOffsetMs(inst, tz))`.
- `nextEvent(ex, date)` — ближайшее событие: цикл `d = 0…7`,
  `wp = wallClock(date + d·DAY)`; не-торговый день пропускается;
  `cand = openNow ? [['close', closeMin]] : [['open', openMin], ['close', closeMin]]`;
  для `d == 0` пропускаются `hm ≤ w0.min`; возврат `{type, at: localToInstant(wp, hm, tz)}`;
  `null` для `always`.

### 3.4 Глифовое поле карты

- `ORB_CHARSET` (70 символов, пробел первый):
  ` .'` + '"' + `^,:;Il!i><~+_-?][}{1)(|/tfjrxnuvczXYUJCLQ0OZmwqpdbkhao*#MW&8%B@$`
- `GLYPH_RAMP` — ранжирование символов по реальной «чернильной плотности»:
  probe-canvas 24×24, шрифт `500 19px monospace`, белый глиф на чёрном,
  `ink = Σ R-канал`; уникальные символы сортированы по ink по возрастанию.
  Fallback (try/catch) — сырой набор в исходном порядке.
- `PAL` — палитра 33 градации: ночь `[6,42,51]` → лёд `[165,243,252]` (t<0.5),
  лёд → белый `[235,253,255]` (k×0.7); `t = i/32`.
- Шум: `fract`, `hash3` (×17-трюк), `noise3` — value-noise, smoothstep-интерполяция
  `f²(3−2f)`, трилинейная. `sstep(a, b, x)`.
- `sunInfo(date)` — деклинация и субсолярная долгота (NOAA, приближение):
  `start = UTC(y, 0, 0)`; `doy = (now − start)/DAY`; `day = ⌊doy⌋`;
  `utcHours = (doy − day)·24`; `g = 2π/365 · (day − 1 + (utcHours − 12)/24)`;
  `decl = 0.006918 − 0.399912·cos g + 0.070257·sin g − 0.006758·cos 2g
  + 0.000907·sin 2g − 0.002697·cos 3g + 0.00148·sin 3g`;
  `eqt = 229.18·(0.000075 + 0.001868·cos g − 0.032077·sin g − 0.014615·cos 2g
  − 0.040849·sin 2g)` (минуты);
  `lon = 180 − 15·(utcHours + eqt/60)`.
- `project(lat, lon, w, h)` — equirectangular, `pad = 14`:
  `x = pad + (lon+180)/360·(w−2·pad)`; `y = pad + (90−lat)/180·(h−2·pad)`.
- `drawMap()` — для каждой ячейки `#` (`lat = 90−(r+0.5)·3`, `lon = −180+(c+0.5)·3`,
  шаг 3° = 180/60 = 360/120), единичный вектор `q = (cosφ·cosλ, cosφ·sinλ, sinφ)`:
  - `drift = (noise3(qx·2.6, qy·2.6 + t·0.039, qz·2.6) − 0.5)·3.2`
  - `bands = 0.5 + 0.5·sin(latR·30 + drift + t·0.2275)`
  - `grain = noise3(qx·11 + t·0.0585, qy·11, qz·11 + t·0.0325)`
  - `albedo = clamp(0.52·bands + 0.33·grain + 0.22)`
  - `sinElev = sinφ·sinδ + cosφ·cosδ·cos(sunLonR − lonR)`; `lit = sstep(−0.1, 0.85, sinElev)`
  - `lampV` (при `str > 0.01`): `s = min(w,h)·0.256`;
    `lampV = str·0.39·exp(−(dx²+dy²)·1.8)`
  - `value = (0.3 + 0.7·albedo)·(0.22 + 0.78·lit) + albedo·0.14·(1 − lit)`
  - `level = pow(min(1, (value + lampV)·1.6), 1.1)`
  - bucketN: `<0.4 → 0`, `<0.75 → 1`, иначе `2`; шрифт меняется только при смене bucket
  - кегли: `fBase = max(7, round(cellW/0.58))`; Mid = `0.88·fBase`; Hi = `0.75·fBase`
  - `gAlb = min(1, 0.12 + albedo·0.95)`; `gi = ⌊gAlb·(len−1) + 0.5⌋`, пропуск `gi < 1`
  - `pi = ⌊min(1, value + lampV·0.65)·32.999⌋` → `PAL[pi]`
  - `alpha = 0.25 + 0.75·min(1, level·1.2)`
  - `fillText(glyph, x, y + cellH·0.06)`
- **Кэш кадра:** ключ = `[⌊now/60000⌋, bucket, sel, hot, clientW, clientH,
  round(dpr·100), round(lamp.x/3), round(lamp.y/3), round(lamp.str·40)].join('|')`;
  `bucket = reduceMotion ? 0 : ⌊mapT·9⌋`. Совпадение ключа — пропуск кадра
  (фактическая частота перерисовки карты ~9/с, цикл — 60 fps).

### 3.6 Шкала времени

- Ось **всегда неподвижна**: сутки `00:00–24:00 UTC` (`dayStart = Date.UTC(utcY, utcMo, utcD)`).
- `rulerRows(now)`: открытые сейчас (не `always`), сортировка по `nextEvent.at`
  по возрастанию (скоро закрывающиеся сверху); затем `hot`, затем `sel`
  (приглушённые, в конец).
- Геометрия: `rowH=16`, `labelW=74`, `tickH=26`, `padT=4`; высота трека
  `= padT + N·rowH + tickH` (пересчитывается под число строк).
- Сетка: полосы каждые 2 часа (`i = 0…23, шаг 2`), ширина `bw/24`,
  `rgba(255,255,255,.025)`.
- Сессии: 288 слотов по 5 минут; сегменты `roundRect(x0, y+3, max(2, x1−x0), 10, r=3)`;
  цвет открытой `rgba(52,211,153,.35)`, закрытой (hot/sel) `rgba(0,212,255,.14)`;
  active — обводка `roundRect(labelW+.5, y+1.5, bw−1, 13, r=4)`,
  `rgba(0,212,255,.4)`, lw=1.
- Подпись кодов: x=2, `y+11`; active — cyan .95, открытая — mint, закрытая — `#6B7280`.
- Тики: 48, major каждые 2; линия `6→17` (major) / `6→11`; подписи major (10px mono):
  UTC — «HH» (`i/2`), LOCAL — локальный час viewerTz в момент `start + i·30 мин`.
- Линия текущего времени: `frac = clamp((now − start)/DAY)`; `x = labelW + frac·bw`;
  градиент amber `rgba(245,158,11,.95 → .25)`, lw=1.6.
- Чип: `left = x/w·100%`; текст `HH:MM UTC|лок`; CSS `transition: left .5s linear`.

### 3.7 Список бирж

- `buildRows` — `innerHTML = ''` в начале (идемпотентность под StrictMode);
  строка: LED, `name + codes`, `row-sub`, `row-cd` (cd-t + cd-l); классы
  `row/crypto/sel/hot`. Клик → `sel = ex.id`, `update()`; hover → `hot`.
- `updateRows` — LED: open (pulse)/closed/always; `sub`:
  «`{дн} {HH}:{MM} лок · сессия {open}–{close}`»; крипта: «`открыт всегда · у вас
  {дн} {HH}:{MM}`», cd «`24 / 7`»; `cd-t = fmtCD(ev.at − now)`;
  `cd-l` = «до открытия» / «до закрытия» (+класс `closed`/`open`).

### 3.8 Тултип карты

- `mousemove`: `lamp.tx/ty = курсор`, `tstr = 1`; ближайший маркер в радиусе
  **16 px** → `hot`; HTML: имя, коды, «● открыта/закрыта», локальное время +
  сессия; `left = min(width−180, x+14)`, `top = max(8, y−62)`, opacity 1.
  Без маркера — `hot = null`, скрытие. Перерисовки — `scheduleUpdate`
  (rAF-дедуп через `tipRaf`).
- `mouseleave` — сброс hot/lamp; `click` — `sel = hot`.

### 3.9 Цикл анимации

- `frame(t)`: `dt = min(1000, t − lastFrame)`; `mapT += dt/1000`;
  сглаживание lamp: `k = 1 − exp(−dt/550)` по x/y/str;
  `update() = drawMap + drawRuler + updateRows`; повторный rAF.
- `prefers-reduced-motion` — `bucket = 0`, фаза шума `t = 12.3` (статика).
- `resize` → `update()`.

### 3.10 Жизненный цикл (нативная встройка)

- `init(root)` — элементы ищутся **внутри root** (не document); canvas 2D
  недоступен → тихий no-op destroy.
- `destroy()` — отмена rAF + снятие всех слушателей (window resize, canvas
  mousemove/mouseleave/click, строки, сег-кнопки). StrictMode-двойной маунт
  безопасен.
- Стейт: `mode` ('UTC' по умолчанию | 'LOCAL'), `sel = 'msc'`, `hot = null`;
  viewerTz = `Intl.DateTimeFormat().resolvedOptions().timeZone || 'UTC'`.

## 7. Известные отклонения порта (зафиксированные)

1. **Дубль `sizeCanvas`** — `drawMap` вызывает `sizeCanvas` на каждом
   некэшированном кадре (canvas ресайзится и очищается каждый анимационный
   кадр). Отклонение от эталона, зафиксировано в ТЗ «нативная встройка»;
   исправлять отдельным решением, не в рамках текущего контракта.
2. Headless-фолбэки (не отклонения): canvas 2D null → no-op destroy;
   `GLYPH_RAMP` try/catch → сырой набор символов.
3. Расхождения поставки по ТЗ «нативная встройка»: header/footer виджета не
   перенесены; `font-family` не задаётся (Inter приложения); эталонный
   `<main>` → `div.mr-main` (вложенный `<main>` ломал валидность).
