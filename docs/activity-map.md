## Общее описание

Страница визуализирует новостную активность за последние 12 месяцев тремя способами:

- **Весь рынок** (`scope=all`) — все новости платформы.
- **Весь портфель** (`scope=portfolio`) — новости по тегам текущего пользователя.
- **Тег** (`scope=tag`) — конкретный тикер/tag_id.

Глубина: годовая сетка, дневной дайджест, почасовая сетка за 14 дней. Верхний график: недельные свечи индекса/инструмента + объём/дельта новостей.

## Страница ActivityMap

**Файл:** `src/pages/ActivityMap.tsx`

### Управляющие элементы

1. **Скоупы:** `Весь рынок` / `Весь портфель` / `Тег`.
2. **Масштаб:** `Год` / `День` / `Часы`.
3. **Ввод тега:** появляется при `scope=tag`.
4. **Выбор даты:** появляется при `scale=day`.
5. **Чипы тегов портфеля:** быстрый переход `scope=tag` по тегам из портфеля.
6. **Сегмент индекса:** `Без индекса` / `IMOEX` / `SPY` (для `all`/`portfolio`).
7. **Оверлей сетки:** `Тональность` / `Частота` / `Всплески`.

### Годовой режим (`scale=year`)

Структура сверху вниз:

1. **TopChart** — свечи + volume/дельта. Подсвечивает неделю при ховере сетки.
2. **YearGrid** — 53×7 ячеек. Тап по ячейке открывает карточку дайджеста под сеткой.
3. **DayDigest card** — карточка выбранного дня с ‹ › и ✕.
4. **TickerRows** — мини-сетки по каждому тегу портфеля (только `scope=portfolio`).

### Дневной режим (`scale=day`)

Полноэкранный дайджест новостей за выбранную дату.

### Почасовой режим (`scale=day_hours`)

Таблица 24 часа × 14 дней.

## Компоненты

### `useHeatmapState.ts`

Центральный хук состояния страницы.

- Читает/пишет параметры URL: `scope`, `scale`, `tag_id`, `date`, `index`.
- Параллельно загружает `year` + `candles` (+ `day`/`hours` при необходимости).
- `index=IMOEX` по умолчанию; `none` убирает свечи.

### `TopChart.tsx`

Верхний график.

- Геометрия жёстко привязана к `YearGrid` (ячейка 14px, gap 3px, отступ подписей 22px).
- Верхняя зона: свечи + подпись тикера/цены.
- Нижняя зона: нулевая линия, дельта `pos−neg` вверх/вниз от неё, volume бледным фоном.
- Всплывашка при ховере: O/Макс/Мин/З, Δ% за неделю, количество новостей, pos/neg.
- При `candles=null` («Без индекса») рисует только volume+дельта.

### `YearGrid.tsx`

Годовая сетка 7×53.

- Поддерживает три оверлея: `sentiment` (зелёный/красный/циан), `freq` (нейтральный циан), `spikes` (только spike-дни).
- Ховер подсвечивает всю неделю и на графике, и в сетке.
- Тап по ячейке вызывает `onSelectDate`.

### `DayDigest.tsx`

Список новостей дня. Заголовки — ссылки через `Link` на `/news/:id` с `state.background` (открывается модалка).

### `TickerRows.tsx`

Мини-сетки по тегам портфеля. Загружает `/api/news_heatmap/mini-grids?tag_ids=...`.

### `HoursGrid.tsx`

24×14 тепловая карта. Строки — дни, колонки — часы.

### `EmptyStub.tsx`

Заглушка при отсутствии новостей за год.

### `MarketPulseMini.tsx`

Мини-блок на главной (`/`). Публичный fetch `scope=all&scale=year`. Скрывается, если `meta.empty === true`. Клик ведёт на `/activity-map?scope=all&scale=year`.

## Состояние и URL

Все параметры синхронизированы с URL:

| Параметр | Значения | По умолчанию |
|----------|----------|--------------|
| `scope` | `all` \| `portfolio` \| `tag` | `portfolio` |
| `scale` | `year` \| `day` \| `day_hours` | `year` |
| `tag_id` | string | — |
| `date` | `YYYY-MM-DD` | сегодня |
| `index` | `none` \| `IMOEX` \| `SPY` | `IMOEX` (только all/portfolio) |

Примеры deep-link:

```
/activity-map?scope=all&scale=year
/activity-map?scope=tag&tag_id=SBER&scale=year
/activity-map?scope=portfolio&scale=day&date=2026-08-28
/activity-map?scope=all&scale=year&index=SPY
```

## Гостевой доступ

- `/activity-map` **только для авторизованных**.
- Гость видит заглушку и AuthModal с `returnUrl=/activity-map`.
- Публичный мини-блок «Пульс рынка» на главной доступен без входа.

## Проверка

```bash
# 1. Страница открывается и загружает годовую карту
open https://pulse.inside-trade.ru/activity-map

# 2. Deep-link на тег
open https://pulse.inside-trade.ru/activity-map?scope=tag&tag_id=SBER&scale=year

# 3. Переключение оверлея: Тональность → Частота → Всплески
# 4. Тап по ячейке → карточка дайджеста под сеткой с ‹ ›
# 5. Сегмент индекса: Без индекса убирает свечи, оставляет volume+дельта
# 6. Гость: открыть в инкогнито → AuthModal
```
