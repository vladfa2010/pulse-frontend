## Общее описание

Страница визуализирует новостную активность за последние 12 месяцев тремя способами:

- **Весь рынок** (`scope=all`) — все новости платформы.
- **Весь портфель** (`scope=portfolio`) — новости по тегам текущего пользователя.
- **Тег** (`scope=tag`) — конкретный тикер/tag_id.

Глубина: годовая сетка, дневной дайджест, почасовая сетка за 14 дней. Верхний график: недельные свечи индекса/инструмента + объём/дельта новостей.

## Страница ActivityMap

**Файл:** `src/pages/ActivityMap.tsx`

### Управляющие элементы

1. **Скоупы:** `Весь рынок` / `Весь портфель` / `Тег`.
2. **Масштаб:** `Год` / `День` / `Часы`.
3. **Ввод тега:** появляется при `scope=tag`.
4. **Выбор даты:** появляется при `scale=day`.
5. **Чипы тегов портфеля:** быстрый переход `scope=tag` по тегам из портфеля.
6. **Сегмент индекса:** `Без индекса` / `IMOEX` / `SPY` (для `all`/`portfolio`).
7. **Оверлей сетки:** `Тональность` / `Частота` / `Всплески`.

### Годовой режим (`scale=year`)

Структура сверху вниз:

1. **TopChart** — свечи + volume/дельта. Подсвечивает неделю при ховере сетки.
2. **YearGrid** — 53×7 ячеек. Тап по ячейке открывает карточку дайджеста под сеткой.
3. **Legend** — легенда «Меньше □□□□□ Больше» под сеткой; для `sentiment` и `spikes` показываются дополнительные пояснения.
4. **DayDigest card** — карточка выбранного дня с ‹ › и ✕.
5. **TickerRows** — мини-сетки по каждому тегу портфеля (только `scope=portfolio`).

### Дневной режим (`scale=day`)

Полноэкранный дайджест новостей за выбранную дату.

### Почасовой режим (`scale=day_hours`)

Таблица 24 часа × 14 дней.

## Компоненты

### `useHeatmapState.ts`

Центральный хук состояния страницы.

- Читает/пишет параметры URL: `scope`, `scale`, `tag_id`, `date`, `index`.
- Параллельно загружает `year` + `candles` (+ `day`/`hours` при необходимости).
- `index=IMOEX` по умолчанию; `none` убирает свечи.
- `updateParam` использует функциональную форму `setSearchParams`, чтобы несколько изменений URL подряд (например, `setTagId` + `setScope` + `setScale` при клике по тегу) накапливались в одном батче, а не перетирали друг друга (fix3).
- При диплинке `scope=tag` без `tag_id` API не дёргается: ждётся ввод тикера (fix3).

### `TopChart.tsx`

Верхний график.

- Геометрия жёстко привязана к `YearGrid` (ячейка 14px, gap 3px, отступ подписей 22px).
- Верхняя зона: свечи + подпись тикера/цены.
- Нижняя зона: нулевая линия по центру. Дельта и объём растут **от нуля в сторону знака дельты** (вверх — позитив, вниз — негатив); серый бар объёма не пересекает нулевую линию (fix7).
- Всплывашка при ховере: O/Макс/Мин/З, Δ% за неделю, количество новостей, pos/neg.
- При `candles=null` («Без индекса») рисует только volume+дельта.

### `DayDigest.tsx`

Список новостей дня. Заголовки — ссылки через `Link` на `/news/:id` с `state.background` (открывается модалка).

### `TickerRows.tsx`

Мини-сетки по тегам портфеля. Загружает `/api/news_heatmap/mini-grids?tag_ids=...`.

- Каждая мини-сетка — тот же годовой календарь 7×53 (строки = дни недели, колонки = недели), что и основная `YearGrid` (fix8).
- Колонки резиновые (`flex-1`), ячейки фиксированной высоты 9px; на узких экранах включится горизонтальный скролл.
- Заголовок «ТИКЕР · N дней» расположен над сеткой; сетка имеет `margin-left: 22px`, чтобы её колонки совпадали по оси X с основной `YearGrid` (fix9).
- Клик по строке переключает `scope=tag` для выбранного тега.

### `HoursGrid.tsx`

24×14 тепловая карта. Строки — дни, колонки — часы.

### `EmptyStub.tsx`

Заглушка при отсутствии новостей за год.

### `MarketPulseMini.tsx`

Мини-блок на главной (`/`). Публичный fetch `scope=all&scale=year`.

- Проверяет `response.ok` и валидирует payload (`cells` и `quantiles` — массивы).
- При 500/сетевой ошибке/невалидном ответе блок молча скрывается, а не роняет приложение.
- Скрывается, если `meta.empty === true`. Клик ведёт на `/activity-map?scope=all&scale=year`.

### `YearGrid.tsx`

Годовая сетка 7×53.

- Поддерживает три оверлея: `sentiment` (зелёный/красный/циан), `freq` (нейтральный циан), `spikes` (частотная заливка + янтарная точка на spike-днях).
- Ховер подсвечивает всю неделю и на графике, и в сетке.
- Тап по ячейке вызывает `onSelectDate`.
- `cells` и `quantiles` по умолчанию пустые массивы — защита от некорректного вызова.
- Корневой контейнер имеет `overflow-x-auto`: на узких экранах сетка прокручивается внутри карточки, а страница не распирается. При загрузке автоматически скроллится к правому (свежему) краю.
- Подписи месяцев сдвинуты на ширину колонки дней недели (`cellSize + mr-2`) и совпадают по оси с `TopChart`.
- Сетка резиновая (fix5): 53 недели делят доступную ширину поровну (`flex-1`), ячейки — `w-full aspect-square`. Внутренняя обёртка задаёт `minWidth`, чтобы на мобильных ячейки не сжимались менее 10px (mini 8px) — тогда включается горизонтальный скролл.

### `heatColors.ts`

Цветовая модель тепловой сетки.

- **5 уровней яркости** (`L0…L4`): 0 новостей → L0; `1..P50` → L1; `(P50..P75]` → L2; `(P75..P90]` → L3; `>P90` → L4.
- **Яркость растёт с уровнем**: редкие дни бледные, пики яркие.
- **Палитры:**
  - `LV` — нейтральный cyan (`rgba(0,212,255,…)`).
  - `RXU` — позитивный emerald (`rgba(52,211,153,…)`).
  - `RXD` — негативный red (`rgba(239,68,68,…)`).
- `getOverlayColor` выбирает палитру по оверлею: для `sentiment` знак тональности определяет шкалу; дни без перевеса (`sentiment_sign == null`) рисуются как L0. Для `freq` и `spikes` используется нейтральная cyan-шкала.
- В режиме `spikes` янтарная точка 6px (`#F59E0B`) в правом верхнем углу ячейки показывает всплеск; заливка при этом остаётся частотной.

## Состояние и URL

Все параметры синхронизированы с URL:

| Параметр | Значения | По умолчанию |
|----------|----------|--------------|
| `scope` | `all` \| `portfolio` \| `tag` | `portfolio` |
| `scale` | `year` \| `day` \| `day_hours` | `year` |
| `tag_id` | string | — |
| `date` | `YYYY-MM-DD` | сегодня |
| `index` | `none` \| `IMOEX` \| `SPY` | `IMOEX` (только all/portfolio) |

Примеры deep-link:

```
/activity-map?scope=all&scale=year
/activity-map?scope=tag&tag_id=SBER&scale=year
/activity-map?scope=portfolio&scale=day&date=2026-08-28
/activity-map?scope=all&scale=year&index=SPY
```

## Гостевой доступ

- `/activity-map` **только для авторизованных**.
- Гость видит заглушку и AuthModal с `returnUrl=/activity-map`.
- Публичный мини-блок «Пульс рынка» на главной доступен без входа.

## Проверка

```bash
# 1. Страница открывается и загружает годовую карту
open https://pulse.inside-trade.ru/activity-map

# 2. Deep-link на тег
open https://pulse.inside-trade.ru/activity-map?scope=tag&tag_id=SBER&scale=year

# 3. Переключение оверлея: Тональность → Частота → Всплески
# 4. Тап по ячейке → карточка дайджеста под сеткой с ‹ ›
# 5. Сегмент индекса: Без индекса убирает свечи, оставляет volume+дельта
# 6. Гость: открыть в инкогнито → AuthModal

# 7. Клик по чипу тега портфеля / строке TickerRows → URL scope=tag&tag_id=<id>&scale=year, без 400
# 8. Десктоп: правая кромка YearGrid совпадает с правой кромкой TopChart; TickerRows совпадают по колонкам с YearGrid
# 9. Мобильный 375px: YearGrid и TickerRows скроллятся горизонтально внутри карточек, страница не распирается
# 10. TopChart: серые бары объёма не пересекают нулевую линию (под нулём пусто на позитивных неделях)
# 11. Сбой дайджеста дня (отключить бэкенд) → вместо вечного скелетона текст «Не удалось загрузить новости дня»
# 12. Заход /activity-map?scope=tag (без tag_id) → инпут тикера, запросов к API нет
```
