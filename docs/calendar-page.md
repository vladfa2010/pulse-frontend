# Страница «Календарь» (/calendar)

> Публичная страница «Календарь»: каркас для виджетов календарной тематики.
> Не путать с блоком «Календарь инвестора» на главной (`docs/calendar.md`) —
> это его будущий новый дом (см. раздел «План»).

---

## Обзор

- **Роут:** `/calendar` (`src/App.tsx`, lazy-загрузка как у остальных страниц).
- **Страница:** `src/pages/CalendarPage.tsx` — шапка + контейнер под виджеты.
- **Меню:** пункт «Календарь» в `navLinks` (`src/components/Navbar.tsx`),
  между «Каскады» и «Портфель»; виден гостям и авторизованным,
  в десктоп-навигации и мобильном бургер-меню.
- **Доступ:** публичная страница (никаких энтитлментов) — данные о сессиях
  бирж не персональные.

## Состав

### 1. Виджет «Ритм рынков» (ТЗ-194 + ТЗ «нативная встройка»)

Интерактивная карта торговых сессий мировых бирж: глифовое поле ASCII с
реальным днём/ночью (солнечный терминатор по NOAA), таймлайн сессий 00–24 UTC,
список бирж со статусами и обратным отсчётом.

- **Форма поставки:** нативный React-компонент `src/components/market-rhythm/`
  (`MarketRhythm.tsx` — JSX-скелет, `widget-core.ts` — порт эталона раздела 3
  ТЗ-194, `market-rhythm.css` — стили раздела 4, скоуп `.market-rhythm`).
  iframe-встройка отклонена владельцем (ТЗ «нативная встройка +
  X-Frame-Options», 2026-10-31): `public/widgets/` удалён, запросов к
  `/widgets/*` нет. **Контракт кода — эталон ТЗ-194**: формулы/константы/
  параметры меняются только через правку ТЗ; массив `MAP_ROWS` и данные
  бирж переносятся дословно (ревью 25.11 поймало усечение копипасты — падение
  TypeError при отрисовке; правило: переносить программной выгрузкой из ТЗ,
  не руками).
- **Жизненный цикл:** `init(root)` возвращает `destroy()` — отмена rAF и
  снятие всех слушателей (StrictMode-двойной маунт безопасен); элементы
  ищутся внутри контейнера, не `document`.
- **Стили:** все селекторы под скоупом `.market-rhythm` (generic `.row`/`.panel`
  без скоупа пересеклись бы с приложением); `@keyframes pulse` виджета
  переименован в `mr-pulse`; body-градиенты/сканлайны — псевдоэлементы
  контейнера; sans-шрифт наследуется от приложения (Inter).
- **Страница:** `CalendarPage.tsx` рендерит `<MarketRhythm />` + caption
  «Как читать…» паттерном приложения (собственный header/footer виджета не
  переносятся по ТЗ). Двойного скролла нет (фикс-высоты iframe убраны).

### 2. Календарь событий (план)

Блок «Календарь инвестора» (`CalendarBlock`, сейчас внизу главной, см.
`docs/calendar.md`) планируется перенести на эту страницу. На главной
`Home.tsx` его монтирование тогда будет убрано. API (`GET /api/calendar`),
типы и админка не меняются.
