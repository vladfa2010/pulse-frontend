# Страница «Календарь» (/calendar)

> Публичная страница «Календарь»: каркас для виджетов календарной тематики.
> Не путать с блоком «Календарь инвестора» на главной (`docs/calendar.md`) —
> это его будущий новый дом (см. раздел «План»).

---

## Обзор

- **Роут:** `/calendar` (`src/App.tsx`, lazy-загрузка как у остальных страниц).
- **Страница:** `src/pages/CalendarPage.tsx` — шапка + контейнер под виджеты.
- **Меню:** пункт «Календарь» в `navLinks` (`src/components/Navbar.tsx`),
  между «Каскады» и «Портфель»; виден гостям и авторизованным,
  в десктоп-навигации и мобильном бургер-меню.
- **Доступ:** публичная страница (никаких энтитлментов) — данные о сессиях
  бирж не персональные.

## Состав

### 1. Виджет «Ритм рынков» (ТЗ-194)

Интерактивная карта торговых сессий мировых бирж: глифовое поле ASCII с
реальным днём/ночью (солнечный терминатор по NOAA), таймлайн сессий 00–24 UTC,
список бирж со статусами и обратным отсчётом, демо-режим прокрутки суток (6×).

- **Файл:** `public/widgets/market-rhythm/index.html` — единый
  самодостаточный HTML (vanilla JS + canvas 2D, без зависимостей и сети,
  кроме Google Fonts). Копия 1:1 из раздела 3 ТЗ-194 — **замороженный
  артефакт**: любые изменения (цвета, скорость, состав бирж) только через
  правку ТЗ, не по месту.
- **Встраивание:** iframe в `CalendarPage.tsx`:

  ```tsx
  <iframe
    src="/widgets/market-rhythm/index.html"
    loading="lazy"
    sandbox="allow-scripts"
    ...
  />
  ```

  Атрибуты — рекомендация ТЗ-194 Задача 3 (виджет ничего не грузит и наружу
  не стучит, postMessage-протокола нет).
- **Высота iframe:** адаптивная вручную (`h-[1380px] md:h-[920px]`) — на
  мобильном виджет складывается в одну колонку (брейкпоинт 960px) и ему нужно
  больше места. Авто-ресаиз невозможен без протокола, которого у виджета нет.
- **Фон iframe:** `#060606` — совпадает с фоном приложения и виджета, стык
  незаметен.

### 2. Календарь событий (план)

Блок «Календарь инвестора» (`CalendarBlock`, сейчас внизу главной, см.
`docs/calendar.md`) планируется перенести на эту страницу. На главной
`Home.tsx` его монтирование тогда будет убрано. API (`GET /api/calendar`),
типы и админка не меняются.
